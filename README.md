# 识朴 Spoon

> 拍摄手边的食材，剩下的交给 AI —— 帮你决定今晚吃什么。

**识朴 Spoon** 是一个移动端优先的「AI 厨房助手」demo：拍照识别食材 → AI 生成可操作菜谱 → 逐步引导烹饪。整体设计追求简洁、温暖、轻盈，突出「今天就能做」的实用感。

## ✨ 功能特性

- **拍照识别食材**：支持连续拍摄 / 上传多张照片，多图识别后合并去重。
- **AI 生成菜谱**：基于已识别食材，并结合「我的厨房」中的调料、厨具上下文生成菜谱，包含推荐理由、时间 / 份量 / 难度、食材清单与分步做法。
- **温柔的 AI 等待体验**：识别与生成过程使用旋转圆环 + 呼吸光环 + 文案渐变，避免「先空态再替换」的割裂感。
- **我的厨房**：管理菜篮子、调料台、厨具（可增删、快速添加、自定义），让 AI 根据你真实的厨房条件给出最可行的步骤。
- **烹饪模式**：沉浸式分步引导，大字号步骤，完成后打勾记录。
- **做菜笔记 / 收藏 / 历史**：记录做过的菜。

## 🧱 技术栈

- **React 19** + **TypeScript**
- **Vite 7**（开发服务器 / 生产构建）
- **React Router 7**（HashRouter）
- **CSS Modules** + 设计令牌（CSS 变量）
- 状态管理：React Context（轻量全局 store）

## 🚀 快速开始

### 环境要求

- Node.js ≥ 20（推荐 22+）
- npm ≥ 9

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 生产构建（类型检查 + 打包）
npm run build

# 预览生产构建
npm run preview
```

> 建议在浏览器的设备模拟模式下查看（如 iPhone X / 12，视口 375 × 812），以获得最佳移动端预览效果。

## 📁 目录结构

```
src/
├─ components/   # 复用组件（Icon、IngredientToken、AppShell …）
├─ pages/        # 页面（Home、Camera、Recognition、Recipe、Cooking、Profile …）
├─ router/       # 路由表
├─ store/        # 全局状态（AppStore，基于 Context）
├─ services/     # 识别 / 菜谱生成（当前为模拟实现）
├─ mock/         # 模拟数据（食材、菜谱、厨房）
├─ types/        # 类型定义
├─ styles/       # 全局样式与设计令牌
└─ assets/       # 静态资源
```

## ⚠️ 说明

本项目为**教学 / 演示 Demo**：拍照、食材识别、菜谱生成均为前端模拟数据，目前尚未接入任何真实视觉模型或后端服务。识别与生成逻辑位于 `src/services/` 与 `src/mock/`，可在此替换为真实 API
